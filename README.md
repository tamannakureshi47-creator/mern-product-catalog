# Product Catalog

A full-stack **MERN Stack Product Catalog Application** built with React.js, Node.js, Express.js, and MongoDB. The application allows users to manage products through a clean frontend interface connected to a RESTful API.

## 🚀 Features

- **Product Listing** — Fetch and display products from the backend API.
- **Add Products** — Create new products using the product form.
- **Product Details** — View individual product information in a details modal.
- **Delete Products** — Remove products from the catalog.
- **REST API Integration** — Connect the React frontend with the Express backend.
- **Reusable Components** — Organized React components for easier maintenance.
- **Price Formatting** — Consistent product price display.
- **Environment Configuration** — Configure the API URL using environment variables.

## 🧪 Testing the Application

1. Start MongoDB or configure your MongoDB Atlas connection.
2. Start the Express backend.
3. Start the React frontend.
4. Add a new product and verify it appears in the catalog.
5. Open product details and verify the displayed information.
6. Delete a product and verify that it disappears from the list.
